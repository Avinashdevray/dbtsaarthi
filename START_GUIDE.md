# VoiceBot Quick Start Guide

## Prerequisites
- macOS with Homebrew installed
- Python 3.9 (system Python shipped with Xcode Command Line Tools is acceptable)
- Git

## 1. Clone the Repository
```bash
git clone https://github.com/Avinashdevray/dbtsaarthi.git
cd dbtsaarthi
git checkout voicebot  # created by this guide
```

If the `voicebot` branch does not exist yet, create it locally after cloning:
```bash
git checkout -b voicebot
```

## 2. Create and Activate the Virtual Environment
```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Upgrade `pip`
```bash
python -m pip install --upgrade pip
```

## 4. Install Dependencies
```bash
python -m pip install -r requirements.txt
```

## 5. Install FFmpeg (required for Whisper audio preprocessing)
```bash
brew install ffmpeg
```

## 6. Run the Application
```bash
export FLASK_RUN_PORT=5001
python app.py
```
The Flask development server will start on `http://127.0.0.1:5001`.

## 7. Use the App
1. Open the web UI in a browser.
2. Click the microphone button and speak your query.
3. Wait for the transcription and audio response generated by Coqui XTTS.

## 8. Stop the Server
Press `CTRL+C` in the terminal.

## 9. Deactivate the Virtual Environment
```bash
deactivate
```

## 10. Troubleshooting
- **Missing FFmpeg**: Ensure `ffmpeg` is installed and available on your `PATH`.
- **Port already in use**: Start the app on a different port, e.g., `FLASK_RUN_PORT=5002 python app.py`.
- **TensorFlow import errors**: The project hard-disables TensorFlow; ensure you are in the `.venv` environment before running the app.
